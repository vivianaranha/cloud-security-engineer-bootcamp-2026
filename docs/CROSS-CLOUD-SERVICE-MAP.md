# Cross-Cloud Security Capability Map

**Created by School of AI**

## Identity
AWS: IAM / IAM Identity Center  
Azure: Microsoft Entra ID / Azure RBAC  
Google Cloud: Cloud IAM

## Key management
AWS: AWS KMS  
Azure: Azure Key Vault  
Google Cloud: Cloud KMS

## Secrets
AWS: AWS Secrets Manager  
Azure: Azure Key Vault  
Google Cloud: Secret Manager

## Audit
AWS: AWS CloudTrail  
Azure: Azure Activity Log  
Google Cloud: Cloud Audit Logs

## Security posture
AWS: AWS Security Hub  
Azure: Microsoft Defender for Cloud  
Google Cloud: Security Command Center

Learn the **security capability** first; map to provider services second.
